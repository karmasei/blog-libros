# 📚 Del Papel a la Pantalla

## 📌 Descripción
Del Papel a la Pantalla es una aplicación web desarrollada con Python, Flask y SQLite que funciona como un blog dedicado a analizar las diferencias entre obras literarias y sus adaptaciones cinematográficas o televisivas.

El proyecto permite a los usuarios explorar publicaciones sobre distintas sagas y franquicias, registrarse en la plataforma, iniciar sesión de forma segura y participar en la comunidad mediante comentarios e interacciones. Además, incorpora un sistema de perfiles donde cada usuario puede personalizar su información y consultar su historial de participación.

Como parte del desarrollo, se implementaron funciones de autenticación, almacenamiento persistente mediante bases de datos SQLite, gestión de publicaciones y comentarios, sistema de respuestas, edición de perfil y un mecanismo de reacciones mediante "Me gusta", simulando las funcionalidades principales de una plataforma web moderna.

Este proyecto fue desarrollado con el propósito de profundizar en el desarrollo de aplicaciones web utilizando Flask, bases de datos relacionales y buenas prácticas para la gestión de usuarios y contenido dinámico.

## 🔧 Tecnologías
- Python 3
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2
- Werkzeug (Hash de contraseñas)

## 📝 Funciones 
1. **Visualización de publicaciones del blog.**
2. **Registro e inicio de sesión con contraseñas cifradas.**
3. **Autenticación mediante sesiones.**
4. **Creación de nuevas publicaciones.**
5. **Sistema de comentarios.**
6. **Sistema de "Me gusta" para comentarios.**
7. **Respuestas a comentarios.**
8. **Gestión de perfiles de usuario.**
9. **Edición de biografía del perfil.**
10. **Selección de preferencias de contenido.**
11. **Almacenamiento de información mediante SQLite.**
12. **Protección de contraseñas utilizando funciones de hash.**
